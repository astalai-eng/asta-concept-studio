# Asta Concept Studio

A collection of app concepts and prototypes exploring care, patient support, connection and learning.

## Projects

- **Kapwa Care** — multilingual caregiver support prototype: `kapwa/index.html`
- **For Once** — conversation prompt prototype: `for-once/index.html`
- **Med Study** — thorax revision question bank prototype: `med-study/index.html`
- **Dustykid® AI** — research in progress. The current material is an opening-screen reference, not a working HTML prototype.

## Publish with GitHub Pages

In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select branch **main** and folder **/(root)**, then save.

Once GitHub Pages finishes deploying, the prototype URLs will be:

- `https://astalai-eng.github.io/asta-concept-studio/kapwa/`
- `https://astalai-eng.github.io/asta-concept-studio/for-once/`
- `https://astalai-eng.github.io/asta-concept-studio/med-study/`

The root `index.html` is a small project index.

## Prototype notes

These are demonstrations, not launched services. The Med Study email check is a front-end demonstration only, not CUHK authentication. Its optional AI explanation panel requires a visitor's own API key; do not enter a personal key on a shared device. Kapwa uses fictional sample scenarios and is not connected to a real care team. Dustykid remains research in progress.
